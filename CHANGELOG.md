# Что изменено в этой версии RUSTOCK

- Каталог загружает с Supabase 24 товара за запрос вместо загрузки всей таблицы.
- Поиск, сортировка и фильтры выполняются на стороне Supabase.
- Добавлена пагинация каталога и списка товаров в админ-панели.
- Добавлена задержка поиска, чтобы уменьшить количество запросов при вводе.
- Карточки показывают краткое описание, фотографии загружаются лениво.
- Большие фотографии в админ-панели автоматически уменьшаются до 1800 px и по возможности переводятся в WebP.
- Если загрузка нескольких фотографий прерывается, ранее загруженные в этой операции файлы удаляются.
- Улучшены адаптивность, фокус клавиатуры, сообщения об ошибках и метаданные страниц.
- Убрана публичная ссылка на админ-панель из футера.
- Добавлены индексы для сортировки и фильтрации; для уже настроенной базы есть `supabase-performance.sql`.

## Что осталось сделать перед публикацией

- Вписать публичный Supabase anon/publishable key в `config.js` (не service_role/secret).
- Если база была создана старой версией проекта, выполнить `supabase-performance.sql` в Supabase SQL Editor.
- Проверить RLS и роли администратора, а затем протестировать каталог после публикации.


## Исправления по обратной связи
- Возвращена ссылка «Админ-панель» в футер публичного каталога.
- Удалено поле краткого описания из формы добавления/редактирования товара и убран вывод краткого описания из карточек. Существующая колонка в базе не удаляется.
- Убрана яркая белая обводка при фокусе текстовых полей; сохранена сдержанная индикация для ссылок и кнопок.
- Главная страница `index.html` не содержит перенаправления в админ-панель. Если открывается `admin.html`, проверьте адрес в браузере и запускайте именно `index.html` через Live Server.
