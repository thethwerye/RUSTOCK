# RUSTOCK — каталог и панель администратора

Готовая стартовая версия сайта-магазина: чёрный минималистичный интерфейс, поиск по серверу, фильтры наличия, постраничная загрузка каталога (по 24 товара), карточки с несколькими фотографиями, подробное описание и характеристики, панель администратора с постраничным списком товаров с добавлением/редактированием/удалением товаров. База данных и фото хранятся в Supabase.

> Заказы и онлайн-оплата в этой версии не реализованы. Это только каталог.

## 1. Что понадобится

- Компьютер с Windows / macOS / Linux.
- VS Code: https://code.visualstudio.com/
- Аккаунт Supabase: https://supabase.com/
- Расширение VS Code **Live Server** (Ritwick Dey) для локального просмотра: https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer

## 2. Создайте проект Supabase

1. Войдите в Supabase и нажмите **New project**.
2. Задайте имя, пароль базы данных и регион. Сохраните пароль базы в надёжном месте.
3. Дождитесь создания проекта.
4. Откройте **SQL Editor** → **New query**.
5. Откройте файл `supabase-setup.sql` из этой папки, скопируйте его содержимое в SQL Editor и нажмите **Run**.
6. Убедитесь, что запрос завершился без ошибок.

Этот SQL создаёт таблицу товаров, таблицу администраторов, правила безопасности (RLS), индексы для сортировки и хранилище фотографий `product-images`. Если база уже была настроена прежней версией проекта, запустите также `supabase-performance.sql` один раз — он добавляет индексы без удаления данных.

## 3. Создайте учётную запись администратора

1. В Supabase откройте **Authentication → Users**.
2. Нажмите **Add user** / **Create new user**.
3. Введите свой email и надёжный пароль. Если доступна опция подтверждения email, для тестового администратора можно подтвердить его вручную через интерфейс Supabase.
4. После создания пользователя скопируйте его **User UID**.
5. Откройте **SQL Editor → New query** и выполните запрос, заменив UID на свой:
   ```sql
   insert into public.admins (user_id)
   values ('ВСТАВЬТЕ-СЮДА-USER-UID');
   ```
6. Если увидите ошибку о некорректном UUID, проверьте, что скопировали именно User UID без пробелов и кавычек внутри значения.

**Важно:** сама регистрация через страницу сайта недоступна. Войти смогут только пользователи, которых вы добавили в `public.admins`.

## 4. Подключите сайт к Supabase

1. В Supabase откройте **Project Settings → API** (в некоторых версиях интерфейса — **Settings → API Keys**).
2. Скопируйте **Project URL**.
3. Скопируйте **anon / publishable public key**. Не используйте `service_role` или `secret` key.
4. Откройте `config.js` в VS Code и замените значения:
   ```js
   window.RUSTOCK_CONFIG = {
     SUPABASE_URL: "https://ВАШ-ПРОЕКТ.supabase.co",
     SUPABASE_ANON_KEY: "ВАШ_ANON_ИЛИ_PUBLISHABLE_KEY"
   };
   ```
5. Сохраните файл.

Ключ `anon` / `publishable` предназначен для браузера; безопасность обеспечивают политики RLS из SQL. **Никогда не помещайте `service_role` / secret key в `config.js` или любой файл, доступный посетителям.**

## 5. Запустите сайт на компьютере

1. Распакуйте архив в отдельную папку, например `Rustock`.
2. Откройте эту папку через VS Code: **File → Open Folder**.
3. Если ещё не установлено, поставьте расширение **Live Server**.
4. В панели файлов VS Code нажмите правой кнопкой по `index.html` → **Open with Live Server**.
5. Откроется адрес наподобие `http://127.0.0.1:5500`.
6. Каталог находится на главной странице, панель администратора — напрямую по адресу `/admin.html` (доступ защищён входом и RLS).

Если сайт показывает сообщение, что Supabase не настроен, проверьте `config.js`. Если возникает ошибка доступа, убедитесь, что выполнили SQL и добавили свой User UID в `public.admins`.

## 6. Добавление и редактирование товаров

1. Откройте `admin.html`.
2. Войдите с email и паролем пользователя, созданного в Supabase.
3. Заполните название, цену и остальные поля.
4. В характеристиках указывайте по одной строке в формате `Название: значение`, например:
   ```
   Размер: M
   Цвет: Чёрный
   Материал: Хлопок
   ```
5. Выберите одну или несколько фотографий. Поддерживаются JPG, PNG, WEBP и AVIF, максимум 8 МБ на фото; за один раз можно выбрать до 8 файлов, у товара — до 12 фото.
6. Нажмите **Сохранить товар**.
7. Для изменения выберите товар в списке и нажмите **Изменить**. Удалить товар можно кнопкой **Удалить**.

Фотографии загружаются в Supabase Storage, а их URL сохраняются в записи товара. Перед загрузкой браузер пытается уменьшить длинную сторону изображения до 1800 пикселей и конвертировать его в WebP; если конвертация недоступна, используется оригинал. Каталог запрашивает только 24 товара на страницу; поиск, фильтры и сортировка выполняются на стороне Supabase. Админ-панель также загружает список по 25 товаров за раз. Это уменьшает объём данных, загружаемых браузером, и помогает каталогу расти.

## 7. Как опубликовать сайт в интернете

Пока сайт запущен через Live Server, он доступен только для разработки. Для публикации понадобится статический хостинг, поддерживающий HTTPS, например Netlify, Vercel или Cloudflare Pages.

1. Загрузите файлы сайта на выбранный хостинг (`index.html`, `admin.html`, `style.css`, `script.js`, `admin.js`, `config.js`, папку `assets`).
2. Не загружайте в публичный репозиторий пароли, `service_role` key или секреты.
3. Откройте опубликованный URL и проверьте каталог и вход администратора.
4. Для более серьёзного использования добавьте домен и настройте его в хостинге.

Когда будете привязывать сайт к Telegram Mini App, потребуется HTTPS URL и настройка бота через BotFather. Текущая версия — обычный адаптивный сайт и не зависит от Telegram.

## 8. Частые ошибки

- **`Invalid API key`** — перепроверьте URL и anon/publishable key в `config.js`.
- **`relation "products" does not exist`** — не выполнен `supabase-setup.sql` или он выполнен не в том проекте.
- **Вход работает, но товары не сохраняются** — проверьте, добавлен ли User UID в `public.admins`.
- **Фотографии не загружаются** — убедитесь, что SQL создал bucket `product-images`, файл не больше 8 МБ и формат поддерживается.
- **Страница пустая или изменения не видны** — перезагрузите страницу без кеша (`Ctrl+F5`) и проверьте консоль браузера (F12 → Console).

## Замечания по безопасности

- На публичной странице видны только опубликованные записи из `products`; в этой базовой версии все товары в таблице показываются всем посетителям.
- Защита добавления/изменения/удаления и загрузки фото реализована через Supabase Auth + RLS. Не полагайтесь только на скрытие кнопок в интерфейсе.
- Не используйте общий пароль администратора и не передавайте доступ посторонним.
- Перед публикацией проверьте, что тестовые товары, цены и фотографии заменены на настоящие.

- Каталог запрашивает с Supabase только 24 товара на страницу, а не загружает весь список целиком.
- Поиск, фильтр наличия и сортировка выполняются на стороне базы данных.
- Добавлена задержка поиска, чтобы не отправлять запрос на каждый символ.
- В админ-панели список товаров разбит на страницы по 25 записей.
- Фотографии каталога загружаются лениво и декодируются асинхронно.
- В футере каталога есть ссылка на `admin.html`; сама панель защищена входом и RLS.
- Добавлены метаданные, улучшены состояния загрузки, мобильное оформление и доступность элементов.

### Перед публичным запуском

1. Убедитесь, что в `config.js` указан именно публичный `anon`/publishable key. Secret/service_role ключ никогда не должен попадать в браузер.
2. Если база уже существует, выполните `supabase-performance.sql` в SQL Editor, чтобы добавить индексы для постраничной сортировки.
3. Проверьте, что публичное чтение товаров и изображений разрешено, а вставка, редактирование и удаление доступны только пользователю, UID которого внесён в `public.admins`.
4. Убедитесь, что в базе нет тестовых товаров или данных, которые не должны быть публичными.
5. Проверьте каталог на телефоне и компьютере после публикации.

Постраничная загрузка снижает нагрузку на браузер и сеть, но сама по себе не гарантирует работу при любом количестве посетителей. Для большой рекламной кампании нужно отдельно проверить тарифные лимиты Supabase, время запросов и объём передаваемых фотографий. Для полнотекстового поиска по очень большой базе может понадобиться отдельная оптимизация поиска.


### Обновление интерфейса
- Чтобы открыть публичный каталог локально, запускайте `index.html` через Live Server. Адрес должен оканчиваться на `/` или `/index.html`, а не `/admin.html`.
- Ссылка «Админ-панель» находится внизу каталога.
- Поле «Краткое описание для карточки» убрано из формы и не отображается в карточках. Старая колонка `short_description` в Supabase сохранена для совместимости с существующими данными.
